FOFO TECH | execução local

1. Abra um terminal nesta pasta.
2. Execute: python3 -m http.server 8000
3. Acesse: http://127.0.0.1:8000/

Rotas:
- Portal: /
- Dia 1: /dia-1/
- Slides: /encontro-1/

Atalhos dos slides:
- Setas, espaço e swipe: navegar
- O: visão geral
- F: tela cheia
- S ou N: notas
- T: iniciar ou pausar timer
- R: reiniciar timer

Não abra os arquivos diretamente por file://. Use o servidor HTTP local para reproduzir o comportamento do GitHub Pages.
